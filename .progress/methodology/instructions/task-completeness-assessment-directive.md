# Оценка полноты задачи

Перед проверкой убедись, что задача уже признана понятной и на этапе размера не требуется декомпозиция. Если любое из двух условий не выполнено, полноту не оценивай и верни ссылку на незавершённый шаг.

Проверь наличие и достаточность сведений по следующим пунктам:

- краткое объяснение назначения изменения;
- ожидаемое итоговое поведение;
- итоговые контракты при их изменении;
- границы изменения и явно исключённые работы;
- перечень необходимых изменений;
- критерии приёмки;
- зависимости и предварительные условия;
- требования совместимости и миграции;
- ожидаемая обработка ошибок и граничных случаев;
- необходимые проверки;
- изменения эксплуатационной документации;
- непротиворечивость тегов по виду задачи, затронутым контурам и текущей стадии обработки.

Для каждого пункта укажи один из статусов:

- есть и достаточно;
- не применимо для данного вида задачи, с обоснованием неприменимости;
- отсутствует и нужен до перехода на исполнение.

В заключении перечисляй только фактически отсутствующие сведения и объясняй, почему без них возрастает неоднозначность исполнения.
