# Оценка размера задачи

Сначала проверь, была ли задача уже признана понятной. Если нет, зафиксируй, что размер не оценивается, и задай только уточняющие вопросы по понятности.

Если понятность подтверждена, оцени необходимость декомпозиции:

1. Можно ли без потери смысла выделить **самостоятельные, независимые и проверяемые** части,
   после чего они собираются в итоговый контракт без регрессионных рисков?
2. Необходимость декомпозиции вызвана **широкой поверхностью** или **по-настоящему высокой сложностью** задачи?
3. Можно ли уменьшить риск ошибки за счёт поэтапной проверки каждого блока без нарушения конечного результата?

При этом зависимость задач не является самостоятельным основанием для декомпозиции.

Результат должен содержать только:

- короткое заключение о необходимости декомпозиции (нужна/не нужна);
- краткое основание этого вывода.

Не формируй наброски частей, новые подзадачи и изменения исходной постановки.

Если вывод — «требуется декомпозиция», оценку полноты не выполняй и явно зафиксируй это условие.
