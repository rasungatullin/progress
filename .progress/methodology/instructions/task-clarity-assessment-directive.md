# Оценка понятности задачи

Определи, даёт ли текущий набор материалов (название, описание, контекст) однозначное понимание:

- зачем требуется изменение;
- какое итоговое поведение ожидается;
- какие границы изменения задают ожидаемый охват;
- какие существенные решения уже зафиксированы;
- есть ли решения, которые может принять только человек.

Оцени, является ли недостаток явной ясности:

- отсутствием технических сведений, которые можно восстановить из проектного контекста и существующих контрактов;
- отсутствием предметно важной информации, которую не может дать контур и которая необходима для корректного выполнения.

Если после оценки задача остаётся непонятной по предметным причинам, не выполняй оценку размера и полноты:

- зафиксируй короткое заключение о непонятности;
- перечисли минимальный перечень конкретных вопросов для уточнения (в порядке критичности);
- укажи, какие решения должны быть подтверждены человеком перед следующей оценкой.

Если задача понятна, верни только заключение о ясности и короткое основание.
