# Контур авторизации

## 1. Назначение

Контур авторизации предназначен для управления доступом к настройкам, данным запусков, просмотру сведений и внешним операциям.

Его цель состоит в том, чтобы разные действия комплекса проверялись по роли, контуру, операции и области применения.

## 2. Краткое описание

Что получает на вход:

- субъект доступа;
- запрашиваемую операцию;
- политику ролей и разрешений.

Что отдаёт на выход:

- решение о допуске;
- основания разрешения или отказа.

Как работает:

- проверяет корректность операции;
- проходит по ролям субъекта;
- сопоставляет разрешения с контуром, действием и областью;
- возвращает разрешающее или отказное решение.

Чего не делает:

- не хранит секреты внешних систем;
- не выполняет внешние операции;
- не заменяет настройки интеграции.

## 3. Основной состав

В состав контура входят:

- субъект доступа;
- операция доступа;
- роль;
- разрешение;
- политика доступа;
- решение авторизации.

## 4. Практический каркас

Начальный каркас расположен в пакете `internal/authorization`.

Пакет содержит сервис `Service.Authorize` и типы `Principal`, `Operation`, `Policy`, `Role`, `Permission` и `Decision`. Каркас поддерживает точные разрешения и шаблонное значение `*`.
