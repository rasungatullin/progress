# Целевое архитектурное состояние контура аналитики и статистики

## Назначение

Контур аналитики и статистики рассчитывает показатели работы комплекса. Он нужен для оценки не отдельного удачного запуска, а накопленной эффективности маршрутов, действий, профилей, моделей и настроек.

Показатели должны использоваться для диагностики, исследований и управляемого улучшения методик.

## Границы

Контур отвечает за:

- получение выборок запусков и событий;
- расчёт числовых показателей;
- формирование отчётов;
- подготовку данных для контура исследований;
- сравнение срезов по маршрутам и действиям.

Контур не отвечает за:

- выполнение задач;
- изменение методик;
- выбор следующего шага рабочей задачи;
- хранение исходного журнала событий.

## Основные сущности

Образец запуска содержит маршрут, действие, статус, длительность, стоимость и число повторов.

Измерение задаёт имя показателя, числовое значение, единицу измерения и метки.

Отчёт объединяет набор измерений по выборке.

В текущем каркасе этим сущностям соответствуют `RunSample`, `Measurement` и `Report` пакета `internal/analytics`.

## Взаимодействие с другими контурами

### Контур журналирования и наблюдаемости

Поставляет диагностические события и записи запусков.

### Контур исследований

Использует отчёты аналитики для сравнения вариантов методик, профилей и настроек.

### Контур методик

Получает измеримые основания для изменения маршрутов, действий и инструкций.

## Практический каркас

`internal/analytics.Service.Calculate` рассчитывает базовые показатели: общее число запусков, долю успешных завершений, среднюю длительность, суммарную стоимость и число повторов.
