# Контур аналитики и статистики

## 1. Назначение

Контур аналитики и статистики предназначен для расчёта показателей работы комплекса по данным запусков, журналирования и дополнительных источников.

Его цель состоит в измеримой оценке устойчивости маршрутов, стоимости запусков, длительности, числа повторов и пригодности результата.

## 2. Краткое описание

Что получает на вход:

- выборку запусков или событий;
- статус результата;
- длительность;
- стоимость;
- число повторов.

Что отдаёт на выход:

- отчёт показателей;
- числовые измерения;
- единицы измерения и метки.

Как работает:

- считает общее число запусков;
- рассчитывает долю успешных завершений;
- рассчитывает среднюю длительность;
- суммирует стоимость и число повторов.

Чего не делает:

- не выполняет исследования самостоятельно;
- не меняет методики;
- не принимает решение по отдельной рабочей задаче.

## 3. Основной состав

В состав контура входят:

- образец запуска;
- измерение;
- отчёт показателей;
- правила агрегации;
- будущие срезы по маршрутам, действиям и профилям.

## 4. Практический каркас

Начальный каркас расположен в пакете `internal/analytics`.

Пакет содержит сервис `Service.Calculate` и типы `RunSample`, `Measurement` и `Report`. Каркас рассчитывает базовые показатели по набору запусков.
