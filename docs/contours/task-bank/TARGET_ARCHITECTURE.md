# Целевое архитектурное состояние банка задач

## Назначение

Банк задач хранит проверочные наборы для исследований, отладки и сравнительных прогонов. Он позволяет оценивать методики и настройки на воспроизводимых данных, не вмешиваясь в текущие рабочие задачи.

Банк задач не является источником истины для фактического состояния задачи во внешнем трекере.

## Границы

Банк задач отвечает за:

- хранение проверочных задач;
- хранение входных данных и ожидаемых результатов;
- выборку задач по меткам;
- подготовку набора для исследований.

Банк задач не отвечает за:

- чтение актуального внешнего состояния;
- принятие решения по рабочей задаче;
- выполнение действия;
- расчёт итоговых показателей исследования.

## Основные сущности

Задача банка содержит идентификатор, название, входные данные, ожидаемый результат и метки.

Банк объединяет задачи одного проверочного назначения.

Запрос выборки задаёт метки и предельное число элементов.

В текущем каркасе этим сущностям соответствуют `Bank`, `Case` и `Query` пакета `internal/taskbank`.

## Взаимодействие с другими контурами

### Контур исследований

Использует банк задач как воспроизводимый набор для проверки гипотез.

### Контур аналитики и статистики

Получает результаты прогонов по задачам банка и рассчитывает показатели.

### Контур методик

Методические изменения проверяются на задачах банка до переноса в рабочие маршруты.

## Практический каркас

`internal/taskbank.Service.Select` выполняет выборку задач по меткам и возвращает копии элементов. Каркас задаёт минимальный контракт будущего постоянного банка задач.
