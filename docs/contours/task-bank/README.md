# Банк задач

## 1. Назначение

Банк задач предназначен для хранения набора задач и связанных данных, используемых в исследованиях, отладке и сравнительных прогонах.

Его цель состоит в отделении рабочих задач от проверочных наборов, пригодных для воспроизводимого сравнения методик.

## 2. Краткое описание

Что получает на вход:

- набор задач;
- запрос выборки;
- фильтр по меткам;
- ограничение числа элементов.

Что отдаёт на выход:

- выбранные задачи;
- входные данные задачи;
- ожидаемый результат.

Как работает:

- проверяет имя банка;
- проверяет идентификаторы задач;
- отбирает задачи по меткам;
- возвращает копию выбранных элементов.

Чего не делает:

- не определяет текущее состояние рабочей задачи;
- не заменяет внешний трекер;
- не выполняет исследование самостоятельно.

## 3. Основной состав

В состав подсистемы входят:

- банк задач;
- задача банка;
- входные данные;
- ожидаемый результат;
- метки выборки.

## 4. Практический каркас

Начальный каркас расположен в пакете `internal/taskbank`.

Пакет содержит сервис `Service.Select` и типы `Bank`, `Case` и `Query`. Каркас выбирает задачи по набору меток и ограничению размера выборки.
