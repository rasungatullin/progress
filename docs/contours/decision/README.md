# Контур принятия решения

## 1. Назначение

Контур принятия решения предназначен для определения дальнейшего режима обработки по поступившему сигналу, доступному проектному состоянию и данным из внешних систем.

## 2. Основные функции

- классификация сигналов;
- атрибуция задачи и уточнение её инженерного типа;
- анализ ограничений;
- определение дефицита сведений для принятия решения;
- запрос дополнительной информации через интеграционные модули;
- выбор сценария обработки;
- формирование задания на исполнение;
- принятие решения об отложенной обработке, ожидании или отклонении;
- маршрутизация задачи по вычислительным каскадам исполнения.

## 3. Входы и выходы

Входы:

- нормализованный сигнал;
- проектное состояние;
- оперативный контекст;
- данные интеграционных модулей;
- конфигурационные ограничения.

Выходы:

- решение о режиме обработки;
- приоритет задачи;
- указание на отложенное выполнение или отклонение;
- задание для исполнительного контура;
- запрос дополнительного контекста.

## 4. Архитектурная роль

Контур принятия решения является управляющим звеном вычислительного цикла. Его задача состоит в согласовании конкретного режима обработки для разных типов задач, внешних систем и исполнительных профилей.

## 5. Первый прикладной приоритет

На первом прикладном этапе контур должен быть ориентирован на замкнутый цикл задачи разработки:

1. запуск по номеру задачи;
2. передача задачи в кодирующий каскад;
3. открытие запроса на слияние;
4. запуск ревизии и постановка замечаний;
5. передача замечаний на доработку и повторная ревизия;
6. слияние запроса при положительном заключении ревизии.

После стабилизации этого цикла контур должен быть расширен режимами проверки готовности задачи к исполнению и синтеза подробного описания.
