# Контур исследований

## 1. Назначение

Контур исследований предназначен для проверки гипотез об улучшении методик, маршрутов, профилей и настроек комплекса.

Его цель состоит в том, чтобы изменения оценивались на воспроизводимых наборах задач и измеримых показателях, а не только по единичным запускам.

## 2. Краткое описание

Что получает на вход:

- гипотезу исследования;
- банк задач;
- варианты методик или настроек;
- набор показателей.

Что отдаёт на выход:

- план эксперимента;
- диагностические сведения о составе исследования;
- будущие результаты сравнения.

Как работает:

- проверяет гипотезу;
- проверяет наличие вариантов;
- формирует последовательность шагов эксперимента;
- передаёт результаты в аналитику.

Чего не делает:

- не изменяет рабочие маршруты без отдельного решения;
- не запускает рабочие задачи как производственный цикл;
- не заменяет контур аналитики.

## 3. Основной состав

В состав контура входят:

- гипотеза исследования;
- эксперимент;
- вариант методики;
- план эксперимента;
- связь с банком задач и аналитикой.

## 4. Практический каркас

Начальный каркас расположен в пакете `internal/research`.

Пакет содержит сервис `Service.Plan` и типы `Hypothesis`, `Experiment`, `Variant` и `Plan`. Каркас формирует план сравнительного прогона по заданной гипотезе и вариантам.
