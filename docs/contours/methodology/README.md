# Контур методик

## 1. Назначение

Контур методик предназначен для хранения и выбора переносимых описаний инженерного процесса: маршрутов обработки, действий, операций, инструкций для языковой модели и рекомендаций по применению исполнительных профилей.

Его цель состоит в отделении методического описания процесса от локальной доступности ресурсов, авторизации и конкретных внешних систем.

## 2. Краткое описание

Что получает на вход:

- запрос на выбор маршрута или действия;
- каталог методических элементов;
- ограничения текущего рассмотрения.

Что отдаёт на выход:

- выбранный маршрут обработки;
- выбранное действие;
- подходящую инструкцию для языковой модели;
- диагностические сведения о выборе.

Как работает:

- находит маршрут по имени или выбирает маршрут по умолчанию;
- определяет действие, связанное с маршрутом;
- уточняет исполнительный профиль;
- выбирает инструкцию, совместимую с профилем.

Чего не делает:

- не проверяет доступность модели или исполнительного модуля;
- не обращается к внешним источникам;
- не выполняет действие.

## 3. Основной состав

В состав контура входят:

- каталог маршрутов обработки;
- каталог действий;
- каталог инструкций для языковой модели;
- правила выбора методического элемента;
- диагностический результат выбора.

## 4. Практический каркас

Начальный каркас расположен в пакете `internal/methodology`.

Пакет содержит типы `Catalog`, `Route`, `Action`, `Instruction`, `SelectionRequest` и сервис `Service.Select`. Каркас уже выполняет проверку наличия маршрута и действия и возвращает нормализованный результат выбора.
