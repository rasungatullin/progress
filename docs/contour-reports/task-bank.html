Банк задач

Отчёт о наборе проверочных задач и связанных данных для исследований, сравнительных прогонов и отладки методик.

Пакет: internal/taskbank Документация: docs/contours/task-bank Класс: исследовательский контур
К основному отчётуК каноническому описанию

Назначение

Банк задач хранит воспроизводимые проверочные наборы, которые можно использовать для исследований, сравнения методик и диагностики качества маршрутов. Он не является источником текущего состояния рабочих задач.

Схема контура

Сущности и роли

СущностьРоль
CaseПроверочная задача с входными данными, ожидаемым результатом и метками.
BankНабор проверочных задач.
QueryФильтр выборки задач.

Как работает сейчас

  1. Сервис фильтрует задачи банка по запросу.
  2. Контур исследований может использовать банк как источник воспроизводимых случаев.
  3. Постоянное хранилище и формат набора задач пока не закреплены как основной рабочий путь.

Проблемы и вопросы

  • Нужно определить формат хранения проверочных задач.
  • Не закреплены правила обезличивания и обновления задач из рабочих источников.
  • Нужна связь с аналитикой результатов прогонов.
