# Стилистический регламент

Раздел содержит нормативные документы по языку, терминологии и рабочим текстам проекта «Прогресс».

## Состав

- `project-language.md` — образ проекта, стилистическая основа, тон и запрещённая подача.
- `terminology.md` — канонический словарь русских терминов.
- `code-terms.md` — соответствия между кодовыми, AI- и документационными терминами.
- `public-models.md` — правила описания публичных межконтурных моделей.
- `agent-workflows.md` — правила для задач, коммитов, запросов на слияние и ревизионных материалов.
- `review-checklist.md` — проверочный список для стилистической ревизии.

## Порядок применения

Если термин закреплён в `terminology.md`, он используется во всех последующих текстах без параллельных вариантов.

Если имя встречается в коде, CLI, JSON или API, документация использует соответствие из `code-terms.md` или `public-models.md`.

Если новое понятие не покрыто регламентом, оно добавляется в словарь или таблицу соответствий до использования в документации.
