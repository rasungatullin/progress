    Реакция
    
            
    Раздел зарезервирован в навигационном каркасе. Для текущего интерфейса активна история исполнения.
    
          
    

          
    
            
    Интеграция
    
            
    Серверные API сохранены без изменений. Навигация собирает существующие представления в единую рабочую область.
    
          
    

          
    
            
    Решение
    
            
    Каркас остаётся компактным: один навигационный модуль слева и рабочая область справа без второго постоянного бокового блока.
    
          
    

          
    
            
    Профили
    
            
    Профиль исполнения доступен в таблице запусков и в карточке выбранного запуска.
    
          
    

          
    
            
    Верификация
    
            
    Интерфейс не инициирует запись состояния. При отсутствии базы истории отображается пустой read-only результат без создания каталогов данных.
